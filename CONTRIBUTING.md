# Contributing

Thanks for helping improve the Xiaomi kernel branch index.

## Working conventions

- Keep changes device-specific and clearly scoped.
- Do not merge unrelated device branches or duplicate kernel references without a clear reason.
- Preserve the naming structure used by the upstream Xiaomi kernel repository.
- Prefer small, documentation-focused updates when editing the device index.

## Pull request guidance

1. Create a focused branch from the current default branch.
2. Update only the relevant documentation or scripts.
3. Keep examples precise and device-aware.
4. Mention the target device branch or model in the PR summary.

## Branch naming

Use names that reflect the device or target kernel tree, for example:

- `alioth-r-oss`
- `begonia-r-oss`
- `jasmine-q-oss`

## Documentation changes

When editing docs or branch metadata:

- verify the device codename and Android version are accurate
- cite the correct branch link or source tag when available
- avoid unverified claims about vendors or upstream sources

## Questions

Open a discussion or pull request with a short summary of the change and the device model involved.
